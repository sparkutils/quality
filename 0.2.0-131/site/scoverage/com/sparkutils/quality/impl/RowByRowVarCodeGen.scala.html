22  * two encoders over a middle operation.
23  * The generated class itself can create new instances directly, unlike Spark projections that need to go through the
24  * codegen source generation cycle, only the compilation is cached.
25  *
26  * If the expression tree contains stateful expressions with codegenfallback the code must be regenerated against a
27  * fresh tree.
